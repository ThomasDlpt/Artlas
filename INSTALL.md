# Guide d'installation — Artlas

> **Note :** Le projet étant actuellement en phase de conception, les commandes exactes seront confirmées lors de l'initialisation du projet Spring Boot.

---

## 1. Prérequis

* **Git**
* **Java JDK** (version 17 ou 21)
* **Gestionnaire de build Java** : Apache Maven (ou Gradle)

---

## 2. Construction du projet à partir du code source

1. Cloner le dépôt du projet et se placer à la racine :
   ```bash
   git clone https://github.com/ThomasDlpt/Artlas.git
   cd ARTLAS
   ```
